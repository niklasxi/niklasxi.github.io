# A Paper Ocean

A fullscreen Three.js story about human scale and attention. A newspaper folds into a tethered paper boat, then the journey moves from ocean to space.

## Run

```sh
npm ci
npm run dev
```

Open Vite’s local address. Requires WebGL 2. Run `npm run build` for a production build.

Click **Begin journey** or the paper, then follow the on-screen prompts. **Turn newspaper** flips the page.
